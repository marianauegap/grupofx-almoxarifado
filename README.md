# GrupoFX — Sistema de Gestão de Uniformes & EPIs

Sistema web de controle de uniformes, botas e EPIs.

## Tecnologias
- HTML/CSS/JS puro (single-page app)
- Supabase (banco de dados na nuvem)
- Vercel (hospedagem)

## Acesso
- **Almoxarifado**: usuário `almoxarifado` / senha `123`
- **Administrador**: usuário `admin` / senha `123`

## Deploy
Conectado ao Vercel via GitHub. Qualquer push na branch `main` atualiza automaticamente.
